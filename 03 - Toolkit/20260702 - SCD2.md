# EXECUTION PLAN: SCD Type 2 Implementation in Silver Models

Based on the project wiki, existing patterns, and codebase standards, here's your high-level execution plan:

### **Phase 1: Model Development** 
Create three new Silver identity models using SQLMesh's `SCD_TYPE_2` kind:

1. **`silver_patient_identity`** — Patient slowly changing dimension
   - Source: `bronze_centralc9__patient` 
   - Grain: `(patient_key, dw_start_date)`
   - Natural key: `patient_key` (patguid)
   - Tracked attributes: demographics (names, DOB, identifiers)

2. **`silver_provider_identity`** — Provider/Employee slowly changing dimension
   - Source: `bronze_centralc9__employee`
   - Grain: `(provider_key, dw_start_date)`
   - Natural key: `provider_key` (empguid)
   - Tracked attributes: credentials, specialty, contact info

3. **`silver_location_identity`** — Location slowly changing dimension
   - Source: `bronze_centralc9__location`
   - Grain: `(location_key, dw_start_date)`
   - Natural key: `location_key` (locguid)
   - Tracked attributes: name, address, billing details, contact info

### **Phase 2: Unit Testing**
Create test cases for each model covering:
- ✓ New record insertion (DW_CURRENT=TRUE, DW_END_DATE=NULL)
- ✓ Update to existing record (supersession: old record gets DW_END_DATE + DW_CURRENT=FALSE, new record gets DW_CURRENT=TRUE)
- ✓ Source delete handling (soft-delete: set DW_CURRENT=FALSE for deleted records)

### **Phase 3: Audits & Data Quality**
- Add `audits()` blocks to verify no overlapping `DW_CURRENT = TRUE` per business key
- Standard row counts, null checks, uniqueness constraints

### **Phase 4: Validation in Snowflake**
- Run models in dev environment
- Execute test cases
- Query point-in-time data manually

### **1. silver_patient_identity**

```sql
MODEL (
    name @{sqlmesh_catalog}.SILVER.silver_patient_identity,
    kind SCD_TYPE_2 (
        unique_key patient_key
    ),
    grain (patient_key, dw_start_date),
    cron '@daily',
    start '2020-01-01',
    audits (
        not_null(columns := (patient_key, dw_start_date, dw_current)),
        unique_values(columns := (patient_key, dw_start_date)),
        -- Verify no overlapping current records per patient
        assert_no_overlapping_current_rows
    )
);

WITH source_data AS (
    SELECT
        -- Natural key (business key)
        UPPER(TRIM(patguid::VARCHAR)) AS patient_key,
        
        -- Tracked attributes (SCD2 will detect changes to these)
        UPPER(TRIM(persguid::VARCHAR)) AS person_key,
        UPPER(TRIM(patid::VARCHAR)) AS patient_id,
        UPPER(TRIM(locguid::VARCHAR)) AS location_key,
        UPPER(TRIM(empguidorthodontist::VARCHAR)) AS provider_key,
        UPPER(TRIM(ptstatguid::VARCHAR)) AS patient_status_key,
        patdeleted,
        
        -- Audit columns (preserved unchanged from source)
        src_crt_ts,
        src_upd_ts,
        src_sys
        
    FROM @{sqlmesh_catalog}.centralc9.bronze_centralc9__patient
    WHERE patguid IS NOT NULL
)

SELECT
    patient_key,
    person_key,
    patient_id,
    location_key,
    provider_key,
    patient_status_key,
    patdeleted,
    
    -- SCD Type 2 metadata
    src_upd_ts AS dw_start_date,
    '9999-12-31'::TIMESTAMP_NTZ AS dw_end_date,
    TRUE AS dw_current,
    
    -- Audit columns
    src_crt_ts,
    src_upd_ts,
    src_sys,
    CURRENT_TIMESTAMP()::TIMESTAMP_NTZ AS crt_ts,
    CURRENT_TIMESTAMP()::TIMESTAMP_NTZ AS upd_ts
    
FROM source_data
WHERE
    @is_incremental IS FALSE
    OR src_upd_ts > (
        SELECT COALESCE(MAX(src_upd_ts), '1900-01-01'::TIMESTAMP_NTZ)
        FROM @{sqlmesh_catalog}.SILVER.silver_patient_identity
        WHERE dw_current = TRUE
    )
;

-- ========================================================================
-- AUDIT: No overlapping DW_CURRENT = TRUE per patient_key
-- ========================================================================
AUDIT (
    name assert_no_overlapping_current_rows,
    model SQLMESH_DEV.SILVER.silver_patient_identity
);

SELECT patient_key, COUNT(*) AS current_count
FROM @this_model
WHERE dw_current = TRUE
GROUP BY patient_key
HAVING COUNT(*) > 1;
-- Passes if zero rows returned
```
