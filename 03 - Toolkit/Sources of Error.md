
| Error | Description |
| -- | -- |
| Selection Bias | Observed cases are not representative of reality. |
| Survivorship Bias | Only seeing successes or visible outcomes. |
| Sampling Error | Dataset is too small or skewed. |
| Measurement Error | Data collected incorrectly or inconsistently. |
| Aggregation Error | Summary metrics hide important subgroup behavior (Simpson's paradox). |
| Temporal Misattribution | Wrong timing/order of events; cause and effect reversed. |
| Base Rate Neglect | Ignoring underlying frequencies or prevalence. |
| Overgeneralization | Small number of examples extrapolated too broadly. |
| Premature Abstraction | Creating a general rule before sufficient evidence exists. |
| Single-Factor Fallacy | Explaining a complex outcome with one cause. |
| Narrative Fallacy | Constructing a coherent story unsupported by evidence. |
| Scope Omission | Failing to account for important actors, systems, or constraints. |

If you want a clean taxonomy

1.Observation Errors – missing data, sampling bias, measurement error.
2.Context Errors – incomplete context, scope omission, survivorship bias.
3.Causal Errors – hidden variables, reverse causality, false causality.
4.Abstraction Errors – overgeneralization, premature abstraction, narrative fallacy.
5.Aggregation Errors – averaging away important differences, Simpson's paradox.
