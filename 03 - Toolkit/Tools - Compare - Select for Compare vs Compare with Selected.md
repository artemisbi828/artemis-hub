Best option: use VS Code’s built-in side-by-side diff.

In Explorer, expand User and then backup.
Right-click the backup file, 20260409_txt_find_replace.py.
Choose Select for Compare.
Right-click the updated txt_find_replace.py in User.
Choose Compare with Selected.


Fast keyboard-driven alternative: open the updated file, press `Ctrl+Shift+P`, run **File: Compare Active File With...**, then select the backup.
