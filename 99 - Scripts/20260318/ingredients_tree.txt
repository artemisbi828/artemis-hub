================================================================================
DESIGN PATTERNS APPLIED
================================================================================

1. SOLID Principles:
   ✓ Single Responsibility: Each method has one clear purpose
   ✓ Open/Closed: PDFProcessor extensible (e.g., add new extractors)
   ✓ Dependency Inversion: Uses abstract Path objects vs hardcoded strings

2. DRY (Don't Repeat Yourself):
   ✓ sanitize_text() reused across all fields
   ✓ SCHEMA constant enforces single source of truth

3. Fail-Fast with Safety Net:
   ✓ ValidationError raised on row count mismatch
   ✓ Partial output STILL written (outputs/) for debugging
   ✓ Exit codes: 0=success, 1=validation, 2=unexpected

4. Pragmatic Modernism:
   ✓ pathlib over os.path (idiomatic Python 3.11+)
   ✓ Type hints on all methods (Future: enable mypy)
   ✓ Docstrings follow numpy/sphinx style

================================================================================
TROUBLESHOOTING GUIDE
================================================================================

Issue: "ModuleNotFoundError: No module named 'docling'"
Fix:   Ensure venv activated: .venv\Scripts\activate
       Then: pip install -r requirements.txt

Issue: "ImportError: DLL load failed" (Windows)
Fix:   Install Visual C++ Redistributable (required by pypdfium2)
       Download: https://aka.ms/vs/17/release/vc_redist.x64.exe

Issue: Row count ≠ 152 but output exists
Status: Expected! Partial output written for debugging analysis
Action: Check outputs/*.tsv → verify which rows missing/duplicated

Issue: Blank fields showing as empty string instead of "null"
Fix:   Check sanitize_text() → ensure it returns "null" not ""
