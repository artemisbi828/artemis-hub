A lot of engineers, architects, DevOps folks, and product teams use **compressed jargon phrases** that are really shorthand for larger operational concepts.

Think of them as:

```text
Word/Phrase
    ↓
Mental Model
    ↓
Underlying Process
```

For example:

```text
"stable invocation path"

Literally:
  A reliable way to execute something.

Expanded:
  A command, script, executable, or API endpoint whose location and behavior
  are predictable enough to be safely automated.

Example:
  BAD  -> C:\Users\Jonas\Downloads\tool.exe
  GOOD -> C:\Tools\duckdb\duckdb.exe

Result:
  Scripts won't randomly break.
```

# Process / Workflow Vocabulary

## `friction point`

A place where unnecessary effort is required.

```text
Customer Journey
 ├─ Login
 ├─ Search
 ├─ Download  <-- friction point
 └─ Done
```

Example:

> Entering MFA five times is a friction point.

Related:

* pain point
* bottleneck
* blocker
* hurdle

***

## `last friction point`

The final annoyance preventing a process from being smooth.

Example:

```text
99% automated
↓
One manual approval remains
↓
last friction point
```

***

## `happy path`

The ideal scenario where everything works.

Example:

```text
User logs in
→ Data loads
→ Dashboard opens

Happy Path
```

Opposite:

```text
edge cases
error paths
failure paths
```

***

## `preflight check`

Validation before execution.

Origin: aviation.

Example:

```text
Before deployment:
  ✓ Git clean
  ✓ Tests pass
  ✓ Secrets exist

Preflight Complete
```

***

## `bootstrap`

Prepare the minimum required environment.

Example:

```text
New machine
↓
Install Python
Install Packages
Create Config

Bootstrap Environment
```

***

## `auto-bootstrap`

System performs setup automatically.

Example:

```text
Run Script
↓
Package Missing
↓
Auto Install
↓
Continue
```

***

# Git Vocabulary

## `invocation`

A specific execution of a command.

Example:

```powershell
git status
```

That command execution is an invocation.

***

## `revision`

A version of something.

Git meaning:

```text
Commit
Tag
Branch Reference
```

All can represent revisions.

***

## `rev-list`

Git command:

```text
revision list
```

Shows commits reachable from a revision.

Example:

```powershell
git rev-list HEAD
```

Meaning:

```text
Give me all commits that led to HEAD
```

***

## `worktree`

A separate working directory attached to the same repository.

Mental model:

```text
One Repository

├─ Main Folder
├─ Worktree A
├─ Worktree B
└─ Worktree C
```

Each can be on a different branch.

***

## `spin up`

Create quickly and temporarily.

Examples:

```text
spin up a VM
spin up a worktree
spin up a database
spin up a container
```

Means:

```text
Create
Use
Destroy later
```

***

## `isolated worktree`

A worktree that doesn't interfere with another.

Example:

```text
Feature A
Feature B
```

can run simultaneously.

***

# DevOps Vocabulary

## `pipeline`

Automated sequence of steps.

```text
Code
 ↓
Build
 ↓
Test
 ↓
Deploy
```

Pipeline.

***

## `orchestration`

Coordinating many systems together.

Example:

```text
Container A
Container B
Database
Queue

↓ coordinated by

Kubernetes
```

***

## `artifact`

Output produced by a process.

Examples:

```text
DLL
ZIP
Parquet File
Wheel Package
Docker Image
```

Artifacts.

***

## `promotion`

Moving something to a higher environment.

```text
DEV
 ↓
TEST
 ↓
PROD
```

Promotion.

***

## `drift`

Actual state no longer matches expected state.

Example:

```text
Terraform says:
  VM = 16 GB

Someone manually changes:
  VM = 32 GB

Configuration Drift
```

***

# Architecture Vocabulary

## `surface area`

How much complexity or exposure exists.

Example:

```text
1 API Endpoint
```

Small surface area.

```text
200 Endpoints
```

Large surface area.

***

## `blast radius`

How much damage a failure can cause.

Example:

```text
One Dashboard Fails
```

Small blast radius.

```text
Entire Fabric Capacity Fails
```

Large blast radius.

***

## `single source of truth`

Authoritative location.

Example:

```text
Power BI Metric
SQL Metric
Excel Metric
```

Bad.

```text
Semantic Model
```

Single source of truth.

***

## `golden path`

Preferred way to do something.

Example:

```text
Official Git Workflow
Official Deployment Process
Official Access Request Process
```

Golden Path.

# My Favorite "AI / Engineer Speak" Terms

## `paper cut`

Tiny annoyance.

```text
One paper cut = trivial

100 paper cuts = misery
```

***

## `tribal knowledge`

Knowledge living only in people's heads.

Example:

```text
"Ask Steve how the refresh works."
```

Bad sign.

***

## `sharp edge`

A feature that's easy to misuse.

Example:

```text
DELETE FROM table;
```

without WHERE.

Sharp edge.

***

## `footgun`

An extremely dangerous sharp edge.

Example:

```powershell
Remove-Item * -Recurse
```

Wrong directory.

Footgun.

***

## `escape hatch`

Intentional override mechanism.

Example:

```text
Standard Process
      ↓
Need Exception
      ↓
Escape Hatch
```

***

## `guardrail`

Mechanism preventing mistakes.

Examples:

```text
Branch Protection
Code Review
Required Tests
```

Guardrails.

***

# Terms You'll Hear Constantly in Fabric / BI / Data

## `canonical`

Official standardized version.

```text
canonical metric
canonical dimension
canonical definition
```

***

## `lineage`

Where data came from.

```text
Source
 ↓
Landing
 ↓
Silver
 ↓
Gold
 ↓
Power BI
```

Data lineage.

***

## `provenance`

Like lineage, but emphasizing origin and history.

```text
Who created this?
Where did it come from?
When did it change?
```

***

## `semantic collision`

Two people use the same word differently.

Example:

```text
"Collection Rate"

Finance Meaning A
Operations Meaning B
```

Collision.

***

## `semantic drift`

Meaning changes over time.

Example:

```text
2024 Active Patient
≠
2026 Active Patient
```

Same name, different meaning.
