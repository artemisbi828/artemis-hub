# Universal
[{Sublime, Obsidian, VSCode}]

| Keys                | Command                  | Applies To                           |
| ------------------- | ------------------------ | ------------------------------------ |
| Ctrl+Shift+K        | Delete Line              | Native to VS Code → Built AutoHotKey |
| Ctrl+Shift+i        | Add cursor above         | Sublime, Obsidian, VSCode            |
| Ctrl+Shift+m        | Add cursor below         | Sublime, Obsidian, VSCode            |
| Ctrl+D              | Fin**D** next instance   | Sublime, Obsidian, VSCode            |
| Ctrl+P              | Open Package             | Sublime, Obsidian                    |
| Ctrl+o              | Open Find File           | Sublime, Obsidian                    |
| Ctrl + Shift + {[]} | Folding Toggle           | Sublime, Obsidian                    |

| [Multi-Line Cursor] | Keys                                  |
| ------------------- | ------------------------------------- |
| Sublime             | Shift+RClick                          |
| VSCode              | Alt+LClick                            |
| Obsidian            | Alt+Shift+LClick → only in txt blocks |
