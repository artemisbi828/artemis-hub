good ask -- clear precise ask, no problem!
false negative -- crying wolf, but problem really isn't there
workable ask
	• contradictory ask -- new ask contracts original specs, like biodmed repairs being quarterly when original doc x12 -- we can fix it, but you wasted our time b/c it contradicts original specs;
	• vague ask, have info -- "something is not right" but don't know what, but we can reasonably guess
blocked ask
	• false assumption or missing ingredient -- months would auto-calculate, but from what? where? how? -- the ask is based on a pre-cept that is false. 
	• we don't have enough info or client assumes something false
vague ask, nsf info -- "something is not right" but don't know what, we don't have enough info and we're s-o-l (shit out of luck)
